# Tiny Godot Game

One small game, actually shipped. Game-jam scope: a single mechanic, a single
evening's worth of content, finished and on itch.io — not a dream MMO.

## Concept candidates (pick one)

1. **One-Dungeon Micro-Zelda** — top-down, one dungeon: grab the sword, push
   the block, beat three slimes, open the boss door. A love letter to the
   Link's Awakening remake, in original art. *Best fit: you're playing Zelda
   right now; the design reference is fresh.*
2. **Ember Arena** — Vampire-Survivors-like: one arena, escalating waves, pick
   1-of-3 upgrades on level-up. Ability-fantasy itch for a League player.
3. **Torchlight Delver** — your light radius shrinks over time; collect embers
   to push back the dark and reach the exit. One mechanic, real tension.

Scope contract for whichever wins: **one scene of gameplay, one win state, one
lose state, sound on/off, shippable in 4 weekends.**

## Open in Godot

```bash
# Godot 4.x — Project > Import > select project.godot
```

`main.tscn` is a placeholder scene. Replace it with the game's first real
scene once the concept is picked.
